# Product

## Platform

web

## Stack

Static HTML, CSS, and JavaScript for GitHub Pages. The source stays in the shared GitHub repository for pull request review.

## Product Purpose

Introduce Nasaem Fragrances, a perfumery business, and give visitors a way to explore fragrance and reach the brand.

## Brand Commitments

Nasaem Fragrances. Official social reference supplied by the owner is [@nasaem.fragrances](https://www.instagram.com/nasaem.fragrances/).

## Evidence on Hand

The owner supplied sixteen campaign artworks. Names and mood descriptions are drawn from those artworks. Product notes, packaging, sizes, prices, and availability await confirmation. The owner chose online checkout and has yet to set up a provider. While checkout is being set up, visitors can ask the brand about a fragrance on Instagram.


## Discovery journey

Visitors enter through three illustrated questions about scent preference, feeling, and occasion. A local ranking function returns two catalog recommendations. Visitors can backtrack, start over, or go directly to the collection. A future AI guide can reuse the catalog and fragrance detail surface. The current flow stores no answers and uses no external AI service.

The owner supplied the gold-toned identity reference and directed the site to match the painted scent cards. Full campaign art stays visible on collection tiles. Product bottle photography will be supplied separately.
